§Amdahl’s Law is one of a number of models used for predicting the performance of parallel architectures.§Amdahl’s Law is useful for explaining the behaviourof a parallel system and the impact of data dependencies and fabric/network delays, but it is often difficult to use since determining the serial component a priori is not always easy.§Numerous alternative models to Amdahl exist and have been used to analyseperformance of parallel applications.§Examples include Gustafson, Erlang, harmonic speedup, LogPand MRM.

Modelling Parallel Application Behaviour

=== PAGE 9 ===
9
§The most difficult applications are those with significant data dependencies, good examples being 2D or 3D mesh computations.§In a mesh computation, dependencies exist between  individual cells in the mesh.§The result is that the partitioning of the mesh for a distributed application  will impact efficiency and parallel speedup.§A smaller number of processors each doing more work might perform better than a larger number of processors each doing less work individually.

§A very common approach for mesh problems is to initially generate a mesh that is fine enough to solve the problem with acceptable accuracy§This mesh is then divided into a set of submesheseach of which contains some number of vertices and arcs connecting them –each submeshis to be computed on a single core or multi-core CPU§The time to compute each submeshand the messaging load between cores and neighboursmust must be assessed or benchmarked§Smaller submeshescompute faster but generate more traffic between cores –this is a trade-off!

§In general, there does not appear to be any single algorithm which can produce an optimal partitioning for all possible problems. §This is because of the diversity in the different problems to be solved, which result in different patterns of communication between processors.§Many existing classes of applications have good partitioning algorithms available as much research has been done; others do not.§The first step in designing a distributed application, or migrating an application to a distributed system, must be the analysis of how to partition the problem.
